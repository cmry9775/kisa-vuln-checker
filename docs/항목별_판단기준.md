# 항목별 판단 기준 (2026 KISA 가이드)

> Unix 서버 > 1. 계정 관리 / 2. 파일 및 디렉토리 관리

## U-01 root 계정 원격 접속 제한 (상)
- 점검 내용: 원격터미널 접속 차단 설정 적용 여부
- 양호: 원격터미널 미사용, 또는 사용 시 root 직접 접속 차단
- 점검(SSH): /etc/ssh/sshd_config 의 PermitRootLogin 값이 no
- 조치: PermitRootLogin No 설정 후 sshd 재시작
- 참고: CentOS 8·Ubuntu 20.04+는 Telnet 기본 비활성, /etc/securetty 없음

## U-02 비밀번호 관리정책 설정 (상)
- 양호: 비밀번호 관리 정책이 설정된 경우
- 점검(RHEL): /etc/security/pwquality.conf (minlen=8, dcredit/ucredit/lcredit/ocredit=-1)
  또는 /etc/pam.d/system-auth 중 하나라도 설정되어 있으면 양호
- 만료: /etc/login.defs PASS_MAX_DAYS 90, PASS_MIN_DAYS 1
- 참고: 복잡성 최소 요구 값은 반드시 -1로 설정해야 적용됨

## U-03 계정 잠금 임계값 설정 (상)
- 양호: 계정 잠금 임계값이 10회 이하
- 점검(RHEL): /etc/pam.d/system-auth, /etc/pam.d/password-auth 의
  pam_faillock(또는 pam_tally2) deny=10 unlock_time=120
- 참고: RHEL 8+는 authselect 사용 권장, 모듈 경로 틀리면 로그인 불가 주의

## U-04 비밀번호 파일 보호 (상)
- 양호: 쉐도우 비밀번호 사용 또는 비밀번호 암호화 저장
- 점검: /etc/passwd 2번째 필드가 모두 x (root:x:0:0:...), /etc/shadow 존재
- 조치: pwconv 명령으로 쉐도우 적용

## U-05 root 이외의 UID '0' 금지 (상)
- 양호: root와 동일한 UID(0)를 갖는 계정이 없음
- 점검: /etc/passwd 3번째 필드(UID)가 0인 계정이 root뿐
- 조치: usermod -u <새 UID> 로 변경 또는 불필요 계정 제거

## U-14 root 홈·패스 디렉터리 권한 및 패스 설정 (상)
- 양호: PATH 환경변수에 "."이 맨 앞/중간에 없음
- 점검: echo $PATH
- 조치: 환경설정 파일(/etc/profile, ~/.profile, ~/.bashrc)의 PATH에서 "." 제거 또는 맨 뒤로

## U-15 파일 및 디렉토리 소유자 설정 (상)
- 양호: 소유자/그룹이 없는 파일·디렉터리가 없음
- 점검: find / \( -nouser -o -nogroup \) -xdev -ls 2>/dev/null
- 조치: 해당 파일 제거 또는 chown/chgrp로 소유자 변경

## U-16 /etc/passwd 파일 소유자 및 권한 (상)
- 양호: 소유자 root, 권한 644 이하
- 점검: ls -l /etc/passwd  (또는 stat -c '%U %a' /etc/passwd)
- 조치: chown root /etc/passwd; chmod 644 /etc/passwd

## U-17 시스템 시작 스크립트 권한 설정 (상)
- 양호: 시작 스크립트 소유자 root, 일반 사용자 쓰기 권한 제거
- 점검(systemd): ls -al `readlink -f /etc/systemd/system/*`
- 조치: chown root <파일>; chmod o-w <파일>

## U-18 /etc/shadow 파일 소유자 및 권한 (상)
- 양호: 소유자 root, 권한 400 이하
- 점검: ls -l /etc/shadow  (또는 stat -c '%U %a' /etc/shadow)
- 조치: chown root /etc/shadow; chmod 400 /etc/shadow

## U-19 불필요한 서비스 비활성화 (finger·telnet·tftp·talk) (상)
- 점검 내용: 사용하지 않는 서비스가 활성화되어 있는지 여부
- 양호: finger, telnet, tftp, talk 서비스가 비활성화(미설치 포함)
- 점검: /etc/xinetd.d/{finger,telnet,tftp,talk}의 disable 값, /etc/inetd.conf의 주석 여부
- 조치: xinetd.d 설정에서 disable = yes로 변경, 또는 해당 패키지 제거

## U-20 r 계열 서비스 비활성화 (rsh/rlogin/rexec) (상)
- 점검 내용: 평문 인증 기반 r 계열 원격 서비스 및 신뢰 호스트 설정 여부
- 양호: shell/login/exec 서비스 비활성화, hosts.equiv·.rhosts 미사용(또는 내용 없음)
- 점검: /etc/xinetd.d/{shell,login,exec}의 disable 값, /etc/hosts.equiv, ~/.rhosts 존재 여부
- 조치: xinetd.d 설정에서 disable = yes로 변경, hosts.equiv·.rhosts 파일 삭제

## U-21 Anonymous FTP 비활성화 (상)
- 점검 내용: FTP 서버의 익명 접속 허용 여부
- 양호: anonymous_enable이 NO(또는 미설정), 혹은 FTP 서버 미설치(N/A)
- 점검: vsftpd.conf(또는 proftpd.conf)의 anonymous_enable 값
- 조치: anonymous_enable=NO로 설정 후 서비스 재시작

## U-22 SNMP 서비스 및 community string 점검 (상)
- 점검 내용: SNMP community string이 public/private 등 기본값을 사용하는지 여부
- 양호: community string이 기본값이 아니거나 SNMP 미설치(N/A)
- 점검: /etc/snmp/snmpd.conf의 rocommunity/rwcommunity/com2sec 값
- 조치: community 문자열을 추측 불가능한 값으로 변경, 불필요 시 SNMP 서비스 비활성화

## U-23 NFS/NIS 서비스 비활성화 및 접근 통제 (상)
- 점검 내용: NFS 공유 설정의 접근 범위 제한 여부
- 양호: /etc/exports 미사용, 또는 공유 대상 IP가 제한되고 no_root_squash 미사용
- 점검: /etc/exports 내 '*(' 와일드카드 공유 또는 no_root_squash 옵션 존재 여부
- 조치: 불필요한 NFS 공유 제거, 접근 허용 IP를 명시하고 no_root_squash 제거
