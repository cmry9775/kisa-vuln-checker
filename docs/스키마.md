# 결과 JSON 스키마

항목 하나당 JSON 객체 하나. 실제 출력은 `lib/common.sh`의 `emit` 함수가 생성하고,
`run_all.sh`가 배열로 합쳐 `results/`에 저장한다.

| 필드 | 설명 |
| --- | --- |
| id | 항목 코드 (U-01 등) |
| title | 항목명 |
| severity | 중요도 (상/중/하) |
| result | 양호 / 취약 / 수동 / N/A |
| evidence | 판정 근거(실제 설정값 등) |
| remediation | 조치 방법 한 줄 |

## 예시

```json
{
  "id": "U-01",
  "title": "root 계정 원격 접속 제한",
  "severity": "상",
  "result": "취약",
  "evidence": "PermitRootLogin=yes",
  "remediation": "sshd_config에 PermitRootLogin no 설정 후 sshd 재시작"
}
```
