# KISA Unix 서버 취약점 점검 항목 (1차 구현 대상)

> 출처: 2026 주요정보통신기반시설 기술적 취약점 분석·평가 방법 상세가이드 (KISA)
> 범위: Unix 서버 > 1. 계정 관리(p.12~), 2. 파일 및 디렉토리 관리(p.39~)
> 이번 주 구현 10개 — 모두 중요도 '상', 자동 점검 가능

| ID | 항목명 | 영역 | 중요도 | 양호 기준(요약) | 점검 명령(Linux) |
| --- | --- | --- | --- | --- | --- |
| U-01 | root 계정 원격 접속 제한 | 계정 | 상 | PermitRootLogin no | grep -Ei 'permitrootlogin' /etc/ssh/sshd_config |
| U-02 | 비밀번호 관리정책 설정 | 계정 | 상 | 복잡성·만료 정책 설정 | grep minlen /etc/security/pwquality.conf |
| U-03 | 계정 잠금 임계값 설정 | 계정 | 상 | 임계값 10회 이하 | grep faillock /etc/pam.d/system-auth |
| U-04 | 비밀번호 파일 보호 | 계정 | 상 | shadow 사용 | awk -F: '$2!="x"' /etc/passwd |
| U-05 | root 이외의 UID 0 금지 | 계정 | 상 | root 외 UID 0 없음 | awk -F: '$3==0{print $1}' /etc/passwd |
| U-14 | root 홈·패스 디렉터리 권한·패스 | 파일권한 | 상 | PATH에 '.' 없음 | echo $PATH |
| U-15 | 파일 및 디렉토리 소유자 설정 | 파일권한 | 상 | 소유자 없는 파일 없음 | find / -xdev \( -nouser -o -nogroup \) 2>/dev/null |
| U-16 | /etc/passwd 소유자·권한 | 파일권한 | 상 | root, 644 이하 | stat -c '%U %a' /etc/passwd |
| U-17 | 시스템 시작 스크립트 권한 | 파일권한 | 상 | root, 일반 쓰기 불가 | find -L /etc/systemd/system -perm -0002 |
| U-18 | /etc/shadow 소유자·권한 | 파일권한 | 상 | root, 400 이하 | stat -c '%U %a' /etc/shadow |
